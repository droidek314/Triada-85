A home computer that never existed: it counts in trits (−1, 0, +1) instead of bits. It greets you with TRIBASIC: try PRINT 6 * 7, or a program like 10 ASK "RAIN"; R and 20 IF R THEN PRINT "UMBRELLA" MAYBE PRINT "MAYBE" ELSE PRINT "SUN", then RUN. MON opens the monitor (HELP, TERN 42); BASIC comes back. Esc stops a program. Browsers keep a page silent until you press a key or click, so the sound starts then. Needs a keyboard.

The owner's manual; the full version with the debugger is on GitHub.
