A home computer that never existed: it counts in trits (−1, 0, +1) instead of bits. Try HELP, TERN 42 and PEEK 243 3 at the READY. prompt. Browsers keep a page silent until you press a key or click, so the sound starts then. Needs a keyboard.

The owner's manual; the full version with the debugger is on GitHub.
